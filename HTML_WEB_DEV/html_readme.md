# Tags in HTML

1. <h1> to <h6> - Heading tags to highlight important text. (opening and closing tag)

2. <p></p> - Paragraph tag to write a paragraph in the website. (opening and closing tag)
    * <p>lorem50</p> it will give 50 random and for the paragraph.

3. <hr> (horizontal rule) - tag to create a horizontal line. (self closing tag) (only opening tag doesnot need to close)

4. <br> (line break) - used to break the line. (self closing tag)

5. <pre> (pre formatted text) - shows the output as we have written in a file, no need to use <br> and all. (opening and closing tag)

6. <ul> - to create unordered list. (opening and closing tag)
7. <li> - to put an item in the list. (opening and closing tag)
8. <ol> - to create an ordered list. (opening and closing tag)

9. <a href="">Text</a> (anchor tag) - This will convert text to hyperlink. We have to put the URL in the href"" to click and go to the site.
* It also has properties like target="_black" with this the link will open in new tab. (opening and closing tag)

10. <img src="" alt=""> - through this we can add image to out website, to add the image we have to put image address to source and if the address is not working then we can add the alternate text in "alt" attribute that will appear if image does appear. (self closing tag)
* we can also use downloaded image in local device by giving relative path in src attribute.

# Attributes in HTML
* used within the tag to make change in the property of element.

* Attribute in <ul style="list-style-type : square;">
    * we can use 4 attributes in <ul> "none", "disc" "circle", "square".

* Attribute in <ol type="I"> or <ol start = "10"> now the list numbers will start from 10.
    * we can use 5 attributes in <ul> "1", "A", "a", "I", "i".
